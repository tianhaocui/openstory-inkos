OpenStory 是开源项目，我们会在 GitHub 上公开跟踪所有 Bug 和功能请求。在那里提交 Issue 有助于我们确定修复优先级，并让讨论过程保持透明。

## 新建 Issue

前往我们的 Issue 跟踪器报告 Bug 或请求新功能：

[github.com/openstory-so/openstory/issues/new](https://github.com/openstory-so/openstory/issues/new)

提交 Issue 需要一个免费的 GitHub 账户。

## Bug 报告中应包含的信息

一份好的 Bug 报告应便于他人复现问题。请提供：

- **发生了什么** — 清楚描述 Bug
- **预期结果** — 说明你认为应该发生什么
- **复现步骤** — 会触发 Bug 的确切操作
- **截图或录屏** — 视觉资料会非常有帮助
- **浏览器和操作系统** — 例如 macOS 14 上的 Chrome 121
- **控制台错误** — 打开浏览器开发者工具，复制其中的红色错误消息

## 功能请求

对 OpenStory 的新功能有想法？请提交标题以 `Feature:` 开头的 Issue，并说明：

- 你想解决的问题
- 你期望它如何工作
- 你考虑过的其他方案

## 浏览现有 Issue

提交新 Issue 前，建议先搜索[现有 Issue](https://github.com/openstory-so/openstory/issues)——你的 Bug 或想法可能已被记录。在现有 Issue 下留言或点赞，有助于我们评估需求。

## 需要直接支持？

对于账户相关问题或任何你不愿公开讨论的事项，请改为[通过邮件联系我们](/docs/support/contact-us)。

如需举报生成内容（肖像侵权、冒充他人或违法材料），请使用[举报表单](/report)，不要在 GitHub 上提交。
